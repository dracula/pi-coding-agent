### [pi](https://github.com/badlogic/pi-mono)

#### Install using Git

If you are a git user, you can install the theme and keep up to date by cloning the repo:

```bash
git clone https://github.com/dracula/pi.git
```

Then copy the theme file to your pi themes directory:

```bash
mkdir -p ~/.pi/agent/themes
cp pi/dracula.json ~/.pi/agent/themes/
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/dracula/pi/archive/main.zip) option and unzip them.

Then copy the `dracula.json` file to your pi themes directory:

```bash
mkdir -p ~/.pi/agent/themes
cp dracula.json ~/.pi/agent/themes/
```

#### Activating theme

1. Open pi in your terminal;
2. Type `/settings` and press Enter;
3. Select the `dracula` theme from the theme list;
4. Boom! It's working ✨
